# Resume

Drop your actual resume PDF into this folder as `Quentin-Bordelon-Resume.pdf`.

The resume page's download button will automatically link to it at
`/resume/Quentin-Bordelon-Resume.pdf` and force a download.

```bash
mv ~/Downloads/Quentin-Bordelon-Resume.pdf public/resume/
```

Until the file exists, the button falls back to the print-to-PDF option.
